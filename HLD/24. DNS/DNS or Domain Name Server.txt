Translates domain name into ip address

DNS checks local cache (stub resolver) before querying DNS resolver for IP address. run ipconfig/displaydns to check local cache 

The command gives following fields:
1. Record name: domain name or sub-domain name	
2. CNAME record: alias of one domain to another (present only type is 5)
3. A record: contains actual IP (present only when type is 1)

How DNS resolver resolves request?
Two ways: recursive and iterative.

A. RECURSIVE:
1. DNS Resolver asks root (.), does it have any ip address for this domain. There are 13 root servers to resolve the request.
2. If root doesn't have answer, it says ask TLD.
3. If TLD, says I don't have answer, ask godaddy authoritative server.
4. Now if it has, return the ip. 

DNS Zone: it helps to resolve the different sub-domains separately.	

B. ITERATIVE:
In this DNS client is responsible for making above requests not the DNS resolver.
