## Zero to Million Users

### On a small scale, we usually develop a application where a client talk to server which has database within the server.

### In order to handle millions of users request, the application should be able to handle fault tolerance, minimize latency, high user traffic, asynchronous requests etc. To achieve this, we should involve following things in our application-

1. Application server and DB separation (better scaling)
2. Load Balancer (handle high user traffic)
3. Database Replication (fault tolerance - master/slave approach)
4. caching (redis - to reduce load of network calls on db )
5. Multiple Datacenters (reducing latency)
6. CDN (reducing latency across globe)
7. Message queues (kafka - asynchronous requests)
8. Database scaling (sharding - vertical & horizontal)
