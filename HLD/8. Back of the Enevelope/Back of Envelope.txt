Back of Envelope

Its concept which is a quick, rough calculation technique used in High-Level Design (HLD) to estimate system scale, resource requirements, and bottlenecks

### Key Metrics:

1. **CalculatedTraffic & Throughput:** Calculates Queries Per Second (QPS) and network bandwidth requirements (servers).
2. **Storage:** Estimates the raw data storage needed per day, month, and year (factoring in data growth).
3. **Memory & Cache:** Determines the RAM needed to cache a specific percentage (e.g., 20%) of frequently accessed "hot" data.

### CheatSheet
  zeros --> Traffic --> Storage
- 10^3 --> 1Thousand --> KB
- 10^6 --> 1Million --> MB
- 10^9 --> 1Billion --> GB
- 10^12 --> 1Trillion --> TB
- 10^15 --> 1Quadrillion --> PB

Data types storage

- char --> 2bytes
- long/double --> 8bytes
- iamge --> 300kb (avg)


## Estimation of Facebook Daily Active Users

#### Assumptions:

1. Facebook has 1Billion users among which only 25% are active at a time. i.e. DAU = 250Million
2. A user performs 5 read operations and 2 writes operation in a day.
3. For Storage, Suppose every user writes 2 posts daily of 250characters and 10% od DAU, posts 1 image of size 300kb.

**Estimating User Traffic:**
```text
1 user performs 7 quries (read+write) in a day.
Request made per sec 250Million Users X 7 / 86400
= 18K requests/sec
```

**Estimating Storage:**
```text
1 post of 250characters = 500bytes
A user writes 2 posts of 250 characters = 1KB
Also, 1 image takes = 300KB

if 250Million users create posts then 250M X 1KB => 250GB/day of storage required
For image, 10% of DAU posts iamge, 25M X 300KB => 7500GB ~ 8TB/day of storage required

For next years, the stats can go upto:
posts: 250GBx2000 ~ 500TB
image: 5TB x 2000 ~ 10PB
```

**Estimating RAM**

```text
For 1 user, we cache last 5 posts
1 posts takes 500bytes
therefore, 5 posts => 2500bytes ~ 3KB

for 250Million users, we need 250M x 3KB = 750GB of RAM/day.
```

**Estimating Servers**

```text
Assuming a server can hold 75GB in memory data, 
therefore to handle 750GB data, we need 10 such servers (machines)

Assuming latency of 500ms and my one server has 50threads
therefore, I can serve 2 requests in a sec
1 server -> 50 threads -> 100 requests/sec
But I have to server 18K requests/sec
so for that I need 18K/100 => 180 servers
```


### **RESULT**

* No of Servers: 180
* Storage: 500TB (posts) + 16PB (images) for next 5 years
* RAM: 750GB RAM consume daily.
